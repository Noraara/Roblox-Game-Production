# Handoffs

A standalone task can use its brief and code directly. For project knowledge, accept the relevant decision, its source, current scope and unresolved questions. Prefer existing records over new copies of the same facts.

For Blender or Aseprite inputs, record the editable source, export path, intended scale and placement, pivot or alignment, material and alpha requirements, animation tags if applicable, and the approval status. Roblox owns integration checks in the target experience.

If a coordinator supplied an `atlas-workflow/v1` packet, keep project ID, task ID and scope. Return the changed files, decisions, checks with status and evidence, findings, unresolved work and exact next action. A plain delivery summary works for standalone tasks.
